## Overview

Identity answers who is behind a request. A [[entity|User]] is global to the Instance and, alone, grants access to no Organization data.

The problem is well known, so OpenBoard does not seek to differentiate itself here. It is built in-house because a self-hosted Instance cannot depend on an external identity provider.
