## Overview

The Identity Module is part of the single backend deployable of [[system|OpenBoardPlatform]]. It owns the `users` and `sessions` tables in [[container|openboard-db]].

## Rules

- Passwords are stored as Argon2id hashes.
- A session ends after 7 days without use or 30 days after it started (ADR 0006).
- While a Temporary Password is pending, the User can only read their own data, change the password or sign out.

The HTTP contract is in the [OpenAPI document](https://github.com/elyosemite/openboard/blob/main/docs/api/openapi.yaml).
